# Allmat Prisbild

Installable web app that turns product photos into branded price images for Allmat Värmland AB.
Static files only — no backend, no API keys, no running cost.

- Run locally: `node dev/serve.mjs` → http://127.0.0.1:5173/
- Tests: `node --test`
- Deploy: push to GitHub Pages. **Bump `VERSION` in `sw.js` on every deploy.**
- Install on iPhone: open the Pages URL in Safari → Share → Add to Home Screen.
- Design: `docs/superpowers/specs/`, `docs/design/`
